# Discord Football League Management Bot

A Discord-only management bot for a Roblox football league. The bot uses Node.js, TypeScript, discord.js, Prisma, and PostgreSQL.

## GitHub workflow

Source code is versioned with Git and pushed to GitHub. Secrets and local database files are excluded by `.gitignore`.

Never commit `.env`, Discord tokens, database passwords, or production data. Copy `.env.example` to `.env` locally when the project is set up.
